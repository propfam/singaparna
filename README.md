
# Singaparna

Keeps money. That's it.

Thanks to Flutter, it can run on anything you can think of: Android phones, Apple devices, web, and even Windows, provided you have the appropriate build environment.

## Features

- Simple and clear interface
- Cross-platform support
- SQLite-based local storage
- Bar and pie expenses graph


## Installation

Go ahead to the latest version, download the .zip, and run (or build) the app. Don't forget to [install Flutter](https://docs.flutter.dev/install) first, then fulfill [all the requirements](https://docs.flutter.dev/install#target-platform) needed by Flutter to build the app across platforms you wish.
## FAQ

#### Do I need some configs after install?

Nope. Singaparna has been designed to be free of external dependencies. SQLite used by Singaparna doesn't need external configurations. The database will made on devices automatically.

#### What's the code formatter do you use?

Well, if the answer wasn't obvious, it's obviously [Prettier.](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode)
